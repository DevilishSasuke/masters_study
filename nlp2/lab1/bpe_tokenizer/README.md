# BPE-токенизатор для русского текста

Программа обучает символьный **Byte-Pair Encoding (BPE)** словарь на текстах
русской классики и токенизирует произвольные предложения.

Корпус — 5 романов из репозитория
[nevmenandr/word2vec-russian-novels](https://github.com/nevmenandr/word2vec-russian-novels/tree/master/books_before):

- `CrimeAndPunishment.txt` — Преступление и наказание
- `EugeneOnegin.txt` — Евгений Онегин
- `FathersAndSons.txt` — Отцы и дети
- `MasterAndMargarita.txt` — Мастер и Маргарита
- `WarAndPeace.txt` — Война и мир

Суммарно ~5.2 млн символов, 79 914 уникальных слов.

```
│   ├── vocab_1000.json       # словарь на 1000 токенов: {токен: id}

    └── main.py                 # CLI: ввод предложения -> список токенов
```

## Как это работает

### 1. Обучение словаря (`train_bpe.py`)

Классический алгоритм BPE (Sennrich et al., 2016), символьный уровень:

1. Текст разбивается на слова (`\w+` или отдельный знак пунктуации).
2. Каждое слово представляется как последовательность символов + маркер
   конца слова `</w>` (нужен, чтобы токенизатор различал, например,
   `при` в начале слова и `при` как самостоятельное слово-предлог).
3. Считаются частоты всех смежных пар символов по всему корпусу
   (с учётом частоты самих слов).
4. Самая частая пара "склеивается" в новый токен, добавляется в словарь.
5. Шаги 3–4 повторяются, пока словарь не достигнет нужного размера
   (1000 или 3000 токенов).

Для скорости используется инкрементальное обновление статистики пар:
после каждого слияния пересчитываются только слова, которые содержали
эту пару, а не весь корпус заново (обучение 3000-словаря занимает ~10 секунд).

Запуск:
```bash
cd src
python3 train_bpe.py --data-dir ../data --out-dir ../artifacts --vocab-size 1000
python3 train_bpe.py --data-dir ../data --out-dir ../artifacts --vocab-size 3000
```

Результат: начальный алфавит (112 символов — кириллица, латиница из
французских вставок в "Войне и мире", цифры, пунктуация) дополняется
слияниями до нужного размера. Итоговый словарь содержит:
- отдельные буквы (для редких/неизвестных сочетаний),
- частые слоги и морфемы (`ня`, `ни</w>`, `прос`, `ющие</w>`),
- целые частотные слова (при vocab_size=3000: `самых</w>`, `вышел</w>`,
  `почувствовал</w>`).

### 2. Токенизация нового текста (`tokenizer.py`)

Класс `BPETokenizer` загружает `vocab_*.json` и `merges_*.txt` и применяет
**те же самые** правила слияния, в том же порядке, что и при обучении
(стандартный алгоритм энкодинга BPE/GPT-2-токенизатора):

1. Новое слово разбивается на отдельные символы.
2. Среди всех смежных пар символов ищется та, что была выучена раньше
   всех остальных (наименьший "ранг" слияния).
3. Пара склеивается, процесс повторяется, пока не останется
   ни одной выученной пары.
4. Символы/куски, которых не было в обучающем корпусе, заменяются
   на `<unk>`.

## Запуск

```bash
cd src

# словарём на 1000 токенов
python3 main.py --vocab-size 1000 "Мой дядя самых честных правил"

# словарём на 3000 токенов
python3 main.py --vocab-size 3000 "Быть или не быть, вот в чём вопрос!"

# интерактивный режим
python3 main.py
```

Пример вывода:
```
Словарь: 3000 токенов (реально 3004 с учётом спецтокенов)
Входное предложение: Быть или не быть, вот в чём вопрос!
Токены (12): ['быть</w>', 'или</w>', 'не</w>', 'быть</w>', ',</w>', 'вот</w>', 'в</w>', 'ч', 'ё', 'м</w>', 'вопрос</w>', '!</w>']
ID токенов: [475, 305, 153, 475, 116, 445, 142, 101, 110, 128, 1532, 195]
Восстановленный текст: быть или не быть , вот в чём вопрос !
```

Как и ожидается, при словаре 3000 частые слова ("быть", "вышел",
"почувствовал") кодируются целиком одним токеном, а при словаре 1000 —
чаще режутся на слоги. Редкие/незнакомые слова (например,
"нейросети", "технологий") в обоих случаях режутся на более мелкие куски,
вплоть до отдельных букв — в этом и есть смысл BPE: часто встречающееся
кодируется компактно, редкое — всё равно кодируется, просто длиннее.

## Программный интерфейс

```python
from tokenizer import BPETokenizer

tok = BPETokenizer("artifacts/vocab_1000.json", "artifacts/merges_1000.txt")

tokens = tok.encode("Привет, как дела?")   # -> список строк-токенов
ids    = tok.encode_ids("Привет, как дела?")  # -> список чисел (id токенов)
text   = tok.decode(tokens)                 # -> восстановленный текст
```

## Требования

Только стандартная библиотека Python 3 (`re`, `json`, `collections`,
`argparse`) — никаких сторонних зависимостей.
